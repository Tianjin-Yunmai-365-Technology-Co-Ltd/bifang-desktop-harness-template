# 产品规格索引

本目录是产品目标、范围、约束和成功标准的唯一正文来源。

## 写入规则

- 文件名固定为 `YYYYMMDD_product_spec.md`，日期使用需求确认所在时区的自然日。
- 同一天只维护一份产品规格；只有产品目标、边界、约束或成功标准变化时才更新。普通缺陷修复、纯重构、格式整理、测试补强和内部清理不代表上述事实变化，不得据此更新规格或在同一天新建第二份。
- 新自然日首次写入时，必须读取前一份产品规格，将仍有效内容、当日确认和已替代内容综合整理为一份完整的当前规格；不得只记录相对前一日的增量。
- 日期文件是当日完整有效快照。旧文件保留历史，不作为当前规格入口；当前规格始终取日期最新的文件。
- 新下游尚未确认产品目标时，最新文件保持 `Draft` 和明确的 `待确定`，不得继承 Harness 的批准事实。
