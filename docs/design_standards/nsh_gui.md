# NSH GUI 标准

`standard_id = nsh-gui-common-v1`，新项目匹配根 Cargo `interfaces = ["nsh"]`；既有 `interfaces = ["gui"]`、`gui-framework = "nsh"` 保留读取兼容。`nsh-targets` 仅支持 desktop/mobile/web；统一正式 0.4.0 固定提交 `e626a8dd8f8d8b277b9507cfd5ac74d0e67020f3`。TUI 暂不可用，现行标准不启用终端布局。

desktop、mobile、Web 图形目标先应用 [共用基座](ui_foundation.md)。三类目标均使用 Mixed 模式：TSX 组件、NSH `nsh/base` 语义控件、reactive signal 和 Rust native module；共享业务规则留在 Rust core。颜色、字号、间距和断点集中在 TSX Token。TSX 是 NSH 自有运行时，不套用 Tauri CSS、Mantine、React hooks 或 GPUI Entity 合同。

TSX 根组件拥有页面会话，切页保留，退出重置；语言与三态主题使用独立 NSH Storage 偏好，desktop 详细侧栏折叠另存偏好，失败须可见。系统语言来自 `locale()`，用户选择优先，中文/英文和未知语言回退完整。界面文字进入同一翻译模块。控件自身拥有动作，周围容器不代理点击。

desktop 子目标使用左侧栏和固定多窗口，并处理九字段桌面 profile：系统托盘、系统通知、自启、关于页、赞助页、单实例、深链接、全局快捷键、侧栏模式。可选项按字段逐项询问；托盘、单实例、深链接、自启按选择接线，深链接依赖单实例；系统通知和 OS 全局快捷键仍 unavailable/disabled，由能力限制派生关闭。已选关于、赞助和侧栏模式只作用于 desktop。mobile/Web 不询问桌面 profile。mobile 无论屏幕宽度都采用竖向壳层：顶部只保留品牌标题，内容独立滚动，首页与设置用位于滚动区之后的固定底部导航切换，不在顶部重复菜单；两个等宽语义按钮使用至少 48 点触控高度、可访问名称及明显选中态。底栏消费 `safeArea().bottom/left/right`，内容不重复消费底部安全区；顶部标题消费 `safeArea().top`，横向内容也避开安全区。`nsh.json` 的 `statusBar.foreground = auto` 配合 `capabilities.statusBar = true` 让状态栏图标随应用主题切换。Web 继续按窗口宽度回流导航，不申请移动状态栏能力。中央 Token 管理宽窄变化。桌面侧栏分为品牌标题、主导航和底部辅助导航，功能项向下增长，底部按已选赞助、固定设置、已选关于排列；选中项同时使用形状标记和底色，并由语义按钮暴露选中与键盘焦点状态。compact 保留可访问名称；detailed 允许独立持久折叠，窄窗口回流时恢复完整产品名。固定设置显示语言与三态主题，只有选择自启时增加真实 OS 状态开关。禁用页面没有组件/菜单/资源。条件赞助页复用项目本地品牌媒体与声明，不能用标题占位冒充完整支持页。

desktop/mobile/Web 的设置页共用一致的页面宽度、节奏与语义控件：语言和主题分成有标题、说明的卡片区域，用 `nsh/base` 单选组呈现当前选择、键盘焦点及切换状态；仅已选 desktop 自启增加语义开关，状态以 `autostart.get` 为准，读取失败和恢复重试可见，写入中禁用开关，不用普通按钮模拟开关。桌面关于页按联系信息、更新日志和免责声明分区，保留多段声明与双语内容；更新日志折叠状态可操作。桌面赞助页按项目已有品牌资料、档位与支付媒体生成，档位突出插图、名称、价格和权益；内容宽度扣除侧栏及滚动容器内边距，随窗口在一至三列回流，二维码在窄窗口不被裁切。三页的字号、间距、圆角和断点由共用 Token 控制，不在页面里散布独立常数；生成的文案、作者、金额与媒体只取当前项目已确认资料，不把示例项目内容写入模板。

desktop 的 `host.call` 只用于原生窗口、自启状态和已选深链接；单实例、托盘留在宿主，TSX 不复制 OS 状态机。macOS 应用菜单在当前所有者窗口设置并在关闭后移交；Windows/Linux 各窗口独立设置菜单。窗口列表与操作使用固定宿主协议；深链接先由宿主排队、通知可领取，再由 TSX 在订阅后主动领取，避免窗口刚创建时丢事件；已关闭窗口的未领取项转给存活窗口。深链接只恢复窗口，不承担产品路由。初始化用真实 Rust 测试、NSH Mixed 测试和当前宿主 Computer Use 检查菜单、主题、双语、侧栏、窄屏与关闭；Web 另外以实际静态包浏览器检查。不可把 headless 测试或 neutral scaffold 当产品候选验收。平台能力与打包边界见 `$desktop-add-nsh-adapter` 的运行时引用。

TUI 终端布局规则暂不适用；待官方正式工具链具备目标能力并完成独立验证后再恢复。当前不得根据历史预览实现生成、运行、构建或验收 TUI。
