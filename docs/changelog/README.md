# 变更记录索引

本目录是用户和维护者可感知变化的唯一正文来源，分类参考《维护变更日志》规范。Harness 版本使用 `Version.md` 声明的上海时区 `YYYYMMDDHHMM`；下游产品默认遵循语义化版本规范 2.0.0。

## 写入规则

- 文件名固定为 `YYYYMMDD_CHANGELOG.md`，同一天的实际变化持续更新同一文件，并以该日结束时仍有效的最新描述为准。
- 只记录已经发生的新增、变化、修复、移除、安全事项和重要已知问题；已确认但尚未实施的需求只进入 ADR 和计划。
- 已经发生且用户或维护者可感知的行为、契约或维护流程变化写入当日变更记录；内部且不可感知的快速改动不创建记录，也不要求写“不适用”占位。
- 同一未发布日期内的中间态和随后被替代的描述应直接合并或删除，避免把已经失效的规则继续暴露为当前能力。
- 发布准备从日期文件汇总对应版本内容；不得把尚未实现或未验证的能力写成已交付。
- 新下游项目在产品规格仍为 `Draft` 且尚无实际变化时可以只有索引；规格转为 `Approved` 前必须存在真实日期记录。
