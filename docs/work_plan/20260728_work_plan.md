# 当前工作计划

> 记忆日期：2026-07-28

## 目标

基于官方公开资料和当前 Harness 事实，为五人团队形成开源与闭源两份商业化调研 Word 报告，明确首批个人开发者/小型软件公司、低客单价自助交付、终端派生项目、首年付费验证，以及按终端裁剪和未来私有实现组件的可行边界。

## 范围

- [x] 读取当前 Product Spec、Product Status、Agent Policy、工程规则、ADR、Work Plan、验证、许可证与项目相关事实，确认报告是内部研究而非产品或许可变更。
- [x] 检索并核对开发者 AI 采用、规格驱动开发 Harness、Agent 规则、通用模板生成器、桌面框架脚手架和商业桌面模板；保留官方来源、检索日期和变化风险。
- [x] 在同一客户、团队和首年目标下比较完整开源、有限开源、开放核心、闭源交付、终端裁剪和私有组件路线。
- [x] 形成价格区间、90 天验证、五人团队分工、十二个月路线、进入/停止门槛、法律与防复制边界。
- [x] 在仓库根生成两份 DOCX，使用正式商务报告样式、真实表格、编号、页眉页脚、可点击来源和免责声明。
- [x] 对两份 DOCX 执行 ZIP 结构、可访问性审计、逐页渲染和全页视觉检查；修复编号和字体渲染问题后重新验证。
- [x] 更新当日 ADR、Product Status、Work Plan、Changelog 和 `docs/VERIFICATION.md`，运行 Harness validator 并复核最终工作树。

## 不包含

- 不批准或实施开源、双重许可、SaaS、OEM、支付、账户、强 DRM、私有 registry、闭源组件或新的 Agent。
- 不改变 Approved Product Spec、现行双语企业专有许可证、接口契约、Rust 资产、版本或发布状态。
- 不把竞品公开价格或调查样本直接推导为本项目市场规模，不把实验价格写成正式报价。
- 不替代专业法律、税务、投资或市场规模尽调。

## 风险与回退

- 公开资料具有时间性；报告标注 2026-07-28 调研日期，正式决策前重新核对易变价格和状态。
- 文档型能力无法绝对防复制；报告把壁垒定位为持续验证、兼容、交付数据和逐步闭源实现，不承诺技术上不可逆向。
- 五人团队容易被低价客户支持耗尽；所有套餐绑定明确支持边界，并以支持分钟/客户作为扩量门槛。
- 私有组件过早会增加跨平台、协议、签名和升级负担；未满足重复项目和接口稳定门槛时保持在知识库、测试与内部实现层。

## 完成标准

- 两份根目录 Word 报告内容相互独立、观点明确，并覆盖用户确认的客户、价格能力、派生交付和首年验证条件。
- 竞品与开源项目均有可追溯官方来源，事实与推断、价格事实与实验假设清晰分开。
- DOCX 结构无损坏，可访问性审计无高/中等级问题；全部渲染页面无截断、重叠、异常分页或编号串联。
- 项目记忆明确报告不改变当前专有许可和 Product Spec；Harness validator 通过，未把策略建议误报为已实现能力。
