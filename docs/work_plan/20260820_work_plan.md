# 2026-08-20 工作计划

## 目标与路径

采用标准路径，再次审计用户指定终端下游的关于页、赞助页、样式、测试与媒体资源，把真正磨合过的约束、模板和完整产品家族品牌依赖包纳入当前 Harness，并在完成后证明页面模板可用、资源逐字节完整传播且没有来源下游产品身份泄漏。

- 当前任务路径：`标准`。本任务涉及产品边界、Skill 资源结构、React/Mantine 模板、媒体资产、升级传播、validator 与项目记忆；不构建或发布真实下游候选。
- 产品边界：用户明确确认 Harness 产出的产品共享同一品牌，要求把支付二维码、固定价格/联系人、品牌更新 banner 和未使用小图整体纳入条件 GUI Skill。通过 `$desktop-define-product` 把原“模板不提供产品资源”修订为“GUI 下游完整保留品牌支持依赖包，只有已选界面所需资产进入应用 bundle”；来源下游产品名称/标识、路由、服务地址、秘密和遥测实例仍被隔离。
- 当前模板边界：工作树已有前一批 Harness 同步和 Skill `desktop-*` 重命名等未提交修改，全部视为受保护的既有工作；本批只增量修改相关 Skill、事实源、validator 和测试。
- 并行边界：`parallel_worktree_subagents: pending` 且当前工作树不是干净提交基线，本批由单 Agent 串行完成，不启动写入型 Subagent。

## 资源审计矩阵

### 接受、原样传播或重构

- 关于页：产品名/版本来自当前下游权威打包元数据；功能、免责声明、许可、隐私、赞助和检查更新是独立可选区块；默认复用品牌联系人，更新与外部链接仍只经已批准适配器入口处理。
- 赞助页：完整保留共享品牌的三档价格/权益、联系人、中英文文案和双支付码；同时改为响应式列数、主题令牌、文本缩放、键盘/无障碍语义和显式媒体替代文本，不继承固定三栏、最小 800px 或全页 `pointer-events: none`。
- 媒体：逐字节复制 12 张赞助图片与 1 张更新 banner，保留原文件名和尺寸；未使用的图标、箭头和选中态图片也进入品牌包并标为可选/当前未引用。媒体清单记录 MIME、尺寸、SHA-256、用途、品牌/支付敏感性与内部专有复用批准。
- 视频：来源没有已跟踪视频，不伪造“已同步视频”；提供本地图片/视频统一组件，真实视频必须有 controls、字幕、文字稿、可选 poster、无自动播放、reduced-motion 与无远程追踪边界。
- 依赖资产：新增产品实例文档模板、品牌配置、媒体清单、React/Mantine 页面/媒体模板与非空模板测试。完整源资产随 GUI 条件 Skill 传播，只有明确选择的页面资源进入应用 bundle。

### 仍明确排除

- 不同步来源下游产品名称/标识、产品功能文案、版本、路由位置、远端地址、更新/遥测协议、秘密、签名身份、绝对路径或历史验证结论。
- 不在 Harness 根创建产品实例 `docs/GUI_SUPPORT_SURFACES.md`，不因携带支付码或更新 banner 自动启用赞助页、更新检查或任何网络请求。
- 不把静态赞助展示扩成订单、权益、支付状态确认、自动支付或账户业务；这些仍需独立产品/外部副作用范围。
