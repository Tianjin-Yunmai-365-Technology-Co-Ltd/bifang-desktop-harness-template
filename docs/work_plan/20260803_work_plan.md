## 目标与路径

把 Harness 从“所有改动统一走完整链路”改为快速、标准、里程碑三档敏捷闭环，减少低风险任务的固定 Token、文档和验证成本，同时保留高风险与发布任务的硬门禁。

- 当前任务路径：`标准`。原因是维护流程、Skills 和校验器需要跨区域一致修改；本任务不产生产品运行物或发布候选。
- 用户选择：用户可直接指定流程档位；未指定时 Agent 自适应。安全、隐私、数据迁移、外部副作用、建立或改变对外兼容契约和发布类硬门禁只能升级，不能降级。
- 协作：只使用只读 Subagent 并行审计；写入范围重叠，主 Agent 在当前工作树串行修改。
- 不包含：产品业务、接口技术栈、许可证、签名/发布安全边界、真实三平台构建、冒烟、E2E、tag、上传或正式发布。
