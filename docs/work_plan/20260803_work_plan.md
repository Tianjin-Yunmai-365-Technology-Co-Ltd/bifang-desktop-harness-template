## 当前策略解析

- 本仓库是 Harness 源，`docs/AGENT_POLICY.md` 中并行、冒烟与 E2E 仍为等待下游初始化的 `pending`。当前修改范围可在单一工作树串行完成，只使用只读 Subagent 审计，不启动写入型 Worktree。
- 本轮翻译直接基于当前含未提交构建/发布改动的工作树继续，保留并兼容所有重叠内容，不撤销或覆盖既有修改。
- Skill 名称、命令、路径、文件名、代码、配置键、协议字段、枚举、固定状态值、测试标识符、版本、哈希、第三方产品名和技术缩写属于机器或专有词元，不因“英文部分”要求改写。
- 本轮只修改 Rust CLI 构建模型；TUI/MCP/GUI 的统一跨平台产物和签名仍不纳入当前版本。
- 用户授权的是未来构建 Skill 在既有条件下执行候选构建和签名尝试，不是本轮创建签名凭据、运行真实跨平台构建、创建标签、发布上传或正式发布。
- Todo 开发阶段不运行冒烟/E2E；完成后只形成可进入 M1 的 Harness 源码候选，不代替人工最终复核。
