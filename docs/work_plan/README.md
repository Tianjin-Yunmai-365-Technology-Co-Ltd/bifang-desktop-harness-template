# 工作计划索引

本目录是标准/里程碑路径或用户要求持久计划时，当前 Todo、状态和检查点的唯一正文来源。快速路径不创建 Work Plan。

## 写入规则

- 文件名固定为 `YYYYMMDD_work_plan.md`，日期使用计划更新所在时区的自然日。
- 同一天只维护一份工作计划；计划变化后持续整理并更新当日文件，不得为同一天新建第二份。
- 新自然日首次写入时，必须读取前一份工作计划，将仍有效步骤、未完成事项和当日新范围综合重写为一份完整的当前计划；不得只追加增量。
- 日期文件是当日完整有效快照，只保留当前计划。已完成结果进入产品状态、验证、ADR 与变更记录；旧计划文件保留历史，但不作为当前计划入口。
- 标准计划至少包含精简 Todo：稳定 ID、预期行为、影响边界、验证方式及 `pending`、`in_progress`、`blocked`、`done` 之一；是否包含最终检查点取决于交付目的。
- 里程碑计划必须包含对应验证里程碑。Todo 只有实现与相关非空测试或相称替代检查通过后才能标记 `done`；任一非 `done` 项存在时不得进入里程碑、执行冒烟/E2E 或产生已验收结论。
- 验证里程碑记录进入条件、完整真实产物、批准场景、冒烟/E2E 策略解析和失败回流。源码片段、模拟实现、桩实现、占位、中性脚手架或开发预览不能作为可验收产物。
