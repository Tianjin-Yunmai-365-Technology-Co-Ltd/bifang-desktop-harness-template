# Work Plan 索引

本目录是当前已批准变更实施步骤的唯一正文来源。

## 写入规则

- 文件名固定为 `YYYYMMDD_work_plan.md`，日期使用计划更新所在时区的自然日。
- 同一天只维护一份 Work Plan；计划变化后持续整理并更新当日文件，不得为同一天新建第二份。
- 新自然日首次写入时，必须读取前一份 Work Plan，将仍有效步骤、未完成事项和当日新范围综合重写为一份完整的当前计划；不得只追加增量。
- 日期文件是当日完整有效快照，只保留当前计划。已完成结果进入 Product Status、验证、ADR 与 Changelog；旧计划文件保留历史，但不作为当前计划入口。
