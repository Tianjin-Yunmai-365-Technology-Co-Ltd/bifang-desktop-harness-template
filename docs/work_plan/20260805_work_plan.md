## 目标与路径

检查并优化 Harness，使后续下游强制采用 core-first：接口无关业务统一由共享 core 实现，CLI/TUI/MCP/GUI 保持薄适配层；系统托盘等接口或平台特性留在所属适配器，但其业务动作仍委托 core。
