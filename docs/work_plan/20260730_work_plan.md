### 1. 迁移 GUI 自有前端基线（已完成）

- 将 `.agents/skills/add-web-adapter/references/react-frontend-baseline.md` 中仍适用于 Tauri GUI 的 React、TypeScript、Mantine UI、TanStack Router、TanStack Query、Jotai、pnpm、状态所有权和验证规则迁入 `.agents/skills/add-gui-adapter/references/`。

### 2. 删除独立 WEB 能力和当前入口（已完成）

- 删除整个 `.agents/skills/add-web-adapter/`。
- 将初始化与实例化接口集合改为 CLI/TUI/MCP/GUI，删除 `$add-web-adapter` 分派、`_web` 命名、WEB 脚手架、独立发布和 E2E 入口。

- 验证结果：当前入口和可执行契约不再提供独立 WEB；Tauri GUI 仍是受支持适配器，技术栈未被删除或替换。

### 3. 收窄开发环境门禁（已完成）

- 将 `$check-development-environment` 的 Node.js/pnpm 条件从 GUI 或 WEB 收窄为仅 GUI；同步 POSIX、PowerShell、参考资料和说明。

- 验证结果：`python3 .agents/skills/check-development-environment/scripts/test_development_environment_gates.py` 全部通过；静态契约同时检查 Shell 与 PowerShell 仅以 GUI 触发前端门禁。

### 4. 重写 Harness 校验器契约（已完成）

- 验证结果：`python3 scripts/test_validate_harness.py`、Python 编译检查和 `python3 scripts/validate_harness.py` 全部通过。

- 最大风险是 GUI 曾通过 WEB Skill 路径共享 React 基线；必须先迁移并更新正向校验器，再删除 WEB 目录。
- Shell 与 PowerShell 门禁必须同步收窄，避免一端仍接受 WEB 或误把 GUI 变为仅限 Rust。
- 历史文档中的 WEB 记录是过去事实，不等于当前能力残留；完成审计必须按事实源和可执行入口分类，不以全仓零命中作为错误目标。
- 如需回退，按单元恢复删除内容和契约；未来重新引入独立 WEB 必须走新的范围闸门，而不是恢复旧 Skill 目录即宣称支持。
