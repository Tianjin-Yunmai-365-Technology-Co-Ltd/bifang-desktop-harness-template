- 阶段描述过宽可能把设计或文档重新纳入询问；validator 同时要求仅编码触发并拒绝旧的设计阶段触发语句。

- 分钟级时间版本在同一分钟内不能产生两个唯一值；规则要求等待下一分钟。若未来需要更高频率，必须先通过范围闸门调整格式。
