- 当前工作树含用户既有修改；所有变更基于现状增量实施，提交前用完整差异复核，不回退或覆盖未知工作。
- 推送可能遇到远端前进、认证或服务不可用；只执行非强制推送，失败时保留本地提交并如实报告，不改写远端历史。
