# 2026-09-01 工作计划

## 目标与边界

本计划维护 Harness 自身工程层，不在模板根实现具体产品。目标是把已验证的系统通知能力抽成可选 GUI Skill，增加可选开机自启能力，重构初始化 Git 引导和发布自动本地提交，增加 GUI 发布性能门禁，并把工具链与依赖兼容基线升级到当前已验证下界。

- 当前路径：持久计划 + 长期规则 ADR + Harness 工程实施。
- 发布边界：本次只修改 Harness；不构建、签名、公证、上传或发布真实下游候选。实施完成时尚未创建当前仓库提交；项目负责人随后明确授权在最终一致性复核通过后，把本目标的完整改动创建为一次当前仓库本地提交，但不授权 push、tag 或历史改写。
- Git 安全边界：初始化只在最终下游仓库写仓库本地身份；不修改全局 Git 配置，不配置 remote，不 push/tag。发布自动提交只消费已审核且范围明确的本地改动，歧义、秘密、hook 或提交失败时停止。
- 能力缺席边界：未选择系统通知或开机自启时，不得保留对应依赖、权限、插件、设置控件、i18n 或运行时接线。
