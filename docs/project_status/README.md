# Product Status 索引

本目录是当前阶段、已完成事项、待确认项和下一步的唯一正文来源。

## 写入规则

- 文件名固定为 `YYYYMMDD_product_status.md`，日期使用状态更新所在时区的自然日。
- 同一天只维护一份 Product Status；状态变化后持续整理并更新当日文件，不得为同一天新建第二份。
- 新自然日首次写入时，必须读取前一份 Product Status，将仍有效状态与当日变化综合重写为一份完整的当前状态；不得复制流水账或只写增量。
- 日期文件是当日完整有效快照。旧文件保留历史，不作为当前状态入口；当前状态始终取日期最新的文件。
