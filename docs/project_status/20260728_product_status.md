- 检索并核对开发者 AI 使用信号、规格驱动开发 Harness、Agent 项目规则、通用项目生成器、Tauri/Electron 脚手架和付费桌面模板；优先采用官方调查、官方文档、官方仓库和官方产品页。

- 闭源路线确认按目标终端裁剪 Skills 与知识库具有合理性，但它主要减少暴露和支持面，不等于绝对保密。长期私有能力只有在 3–5 个真实付费项目重复后再抽取，优先本地 CLI/伴随进程；私有 Cargo 软件包仓库不作为源码保密手段。
- 两份 DOCX 均通过压缩结构与可访问性审计，高/中等级问题为零；9 页和 11 页全部完成渲染与逐页视觉检查。

## 未验证与剩余风险

- 报告中的人民币价格、转化率、支持时长和季度门槛均是实验假设，尚无真实陌生客户订单证明。
- 竞品功能、价格、星标数和发布状态会变化；正式定价或对外比较前需要重新核对。
- 当前专有许可证仍需专业律师针对真实主体、客户、地区、开源依赖与交易文件复核；本次报告不构成法律、税务或投资意见。
- 尚未实现自助下单、自动生成、终端裁剪、许可校验、私有组件或升级机制；不得把策略建议描述成现有能力。
- 真实 `$instantiate-project`、Windows/Linux、非 CLI 适配器和最终客户交付仍沿用既有 `Unverified` 边界。
