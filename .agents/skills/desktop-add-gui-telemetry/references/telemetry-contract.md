# GUI 统计同意与传输合同

真实产品目的、接收端和隐私说明只写受保护的 docs/GUI_SUPPORT_SURFACES.md；本合同不启用能力或收集实例数据。

## 统计上报同意与固定最小事件

- 统计上报是独立能力，默认关闭。首次启动和未同意时零出站；不得把安装、使用或检查更新视为同意，也不得用免责声明替代明确开关。
- 同意由 GUI adapter 保存在设备级本地偏好中。用户打开后只从下一次符合条件的事件开始发送，不回补同意前事件；关闭时立即取消在途上报、清空内存队列并阻止后续入队。
- 固定基线只允许一次每进程的 `app_started` 事件，使用 JSON `POST` body，字段精确为：`schemaVersion`、`eventName`、公开的 `applicationCode`、`applicationVersion`、粗粒度 `osFamily`、`architecture`、`locale`、`distributionChannel`、`occurredAtUtc`。
- 禁止使用 GET/query 传递事件；禁止稳定设备 ID、安装 ID、用户名、主机名、IP 派生字段、精确系统版本、绝对路径、文件名、窗口标题、命令参数、账号、令牌、业务载荷或自由文本。新增事件、字段或稳定标识符必须重新经过产品、隐私和适用法律批准。
- 桌面客户端不持有服务端 secret。若接收端要求认证，必须采用不会把长期发布者/服务端身份秘密放进 bundle 的批准方案；否则停止实现。

## 上报传输与回收

- endpoint 必须是产品 profile 中允许的 HTTPS origin/固定路径，不允许任意重定向、远程下发新 endpoint 或前端直接请求。
- GUI Rust adapter 拥有传输；React 只读配置状态并提交同意变化。shared core 只在统计资格需要跨接口复用时拥有语言无关的资格规则，不持有平台元数据或 HTTP client。
- 每个进程最多一个发送任务、一个在途请求和 32 条内存事件；不落盘。连接超时最多 5 秒、总超时最多 10 秒，失败最多重试 2 次，退避为 1 秒和 4 秒并带有界抖动；应用关闭、撤回同意或队列满时丢弃而不阻断主要业务。
- 统计失败始终 fail-open。日志只记录稳定事件名、结果码和队列计数，不记录 body、endpoint query 或设备信息。

## 产品实例必填事实

启用统计上报时至少填写：

- 明确目的、同意文案、公开 `applicationCode`、distribution channel 和唯一允许事件/字段；
- HTTPS origin/路径、方法、内容类型、超时、重试、队列、保留与服务端删除期限；
- 接收方、隐私责任人、适用法律依据、退出/删除路径和用户可见隐私说明；
- 禁止字段清单、日志脱敏、零出站证明与真实撤回验证。

## 必需回归

- 统计：未配置、默认关闭、未同意、撤回同意均为零出站；只使用 POST body 和固定字段；禁止稳定标识符；队列/重试有界且关闭后无遗留任务。
