# Linux 原生宿主方案

只在修改 Linux 窗口、托盘、自启、通知或后台热键机制时读取。这里收录从下游实践中提炼的可复用方法，不是中性 renderer 的能力清单。当前 renderer 仍拒绝生成 Linux 托盘与后台热键；也未生成下文的完整登录命令校验、旧项迁移和隐藏启动协调。扩展须在已批准的下游范围内独立接线、回归和取证。具体版本、产品策略及历史验收结果留在目标项目。

## 图形会话与窗口

启动前捕获会话能力。确需全局定位或置顶且存在有效 `DISPLAY` 的产品，可按批准需求选择 X11/XWayland；不要为选择后端改写进程环境。纯 Wayland 普通 toplevel 不承诺相同的全局定位和置顶合同；未接通协议路径时明确失败并保留恢复入口，不能以激活窗口代替置顶。

X11 使用真实 XID 与 checked request。需要持久化全局几何时明确使用 root 物理坐标，仅在原生边界换算 DIP；工作区按 RandR 活动显示器与当前桌面 `_NET_WORKAREA` 求交，缺协议时才回退 root 几何。混合 DPI 与热插拔另行实测。

[EWMH](https://specifications.freedesktop.org/wm/latest/) 置顶是窗口管理器协商状态。首次 map 后重新核对请求，以有总预算的异步观察确认状态，再验证实际覆盖关系，不阻塞主循环。确认后释放临时几何或显隐目标，避免旧目标拦住拖动或输入穿透切换。Shape Input 与视觉区域分别拥有；写后读回，失败尝试恢复，恢复失败披露未知状态。需要保存偏好时，原生效果确认后才提交，退出接管已接受但尚未提交的最后意图。

## 托盘与关闭恢复

KSNI/StatusNotifierItem 使用会话 D-Bus，不在 GPUI 主线程混入 GTK 循环。对象创建不证明窗口可恢复：后台有界 worker 联合核对 Watcher 的真实 host、注册列表、服务连接的进程 ID 和预期托盘 ID。注册项可能使用 KDE 的 `service/path`、GNOME 的 `service@/path`，或只有服务名；后者使用标准对象路径。解析后核对绝对对象路径，再查归属，不能因其它应用有托盘就确认自身可恢复。owner 变化、注销、断连或未知结果撤销旧可用性；主线程只读已发布事实。

关闭回调已经借用当前 GPUI 窗口，不可在其中再次 update 同窗取得 XID。在安装机制时捕获所需原生能力；关闭及延迟隐藏阶段仍重新核对恢复入口。缺少可靠入口时允许正常关闭，不能隐藏到不可恢复状态。最终验收操作真实托盘恢复和退出，D-Bus 属性读回不代替点击。

托盘丢失后恢复已隐藏窗口时，只有原生显窗成功才清除隐藏事实；请求失败仍保留待恢复状态，沿已有生命周期重试。手动显窗和退出使旧延迟隐藏/启动等待代次失效，避免迟到任务重新隐藏窗口。

## 托盘与任务栏协同

只有产品明确选择“可靠托盘接管后隐藏任务栏入口”时才采用；中性窗口不默认增加该行为。X11/XWayland 主窗仍保留普通窗口类型，按当前恢复入口申请 `_NET_WM_STATE_SKIP_TASKBAR`；入口失效则撤销该意图并恢复已隐藏主窗。纯 Wayland 没有这条 EWMH 路径，保留普通入口，不为隐藏任务栏擅自切换后端。

依照 EWMH 的窗口状态合同，只有撤回窗口可以由客户端准备初始 `_NET_WM_STATE`；`UNMAPPED` 本身不证明撤回，还要核对 `WM_STATE`，最小化窗口仍归窗口管理器管理。读取属性时确认类型、格式及完整性，只增删目标 atom，保留最大化、置顶等其它状态。已管理窗口向 root 发送 ClientMessage，不能直接覆盖窗口管理器拥有的状态属性。

窗口管理器可能在撤回或重新 map 时删改状态。显窗前准备允许写入的初始状态，map 后无条件补发请求，并使下一轮托盘同步重发；常态只在恢复入口变化或请求失败时发送，避免持续访问 X11。缓存表示“已发送意图”，不是窗口管理器已应用的状态；失败后连旧缓存也失效。协议回执、状态读回和真实任务栏/Dock 呈现分别取证。

## 登录项与隐藏启动

自启能力的授权和串行 OS 读写继续由 [$desktop-add-gpui-autostart](../../desktop-add-gpui-autostart/SKILL.md) 管理。读取登录项须跟实际写入驱动使用同一路径解析，不能凭 XDG 规范猜测库的实现：已核对的 `auto-launch 0.6.0` 使用 `dirs::home_dir()` 下的 `.config/autostart/<app-name>.desktop`，没有读取 `XDG_CONFIG_HOME`；直接使用 `HOME` 会漏掉库的 passwd 回退。更换驱动或版本时重核源码，不能据此把这个布局变成全部 Linux 应用的规则。

库的 `is_enabled()` 可能只检查文件存在。需要确认当前启动目标/参数时，有界读取本应用条目，区分缺失、权限失败、无效 UTF-8 和超限；只接受主 `[Desktop Entry]` 组中唯一的完整 `Exec`，核对与写入端相同的命令编码及全部参数，并尊重 `Hidden=true`、`X-GNOME-Autostart-enabled=false`。重复主组/Exec 是歧义，不能当开启。不得把受限解析器当作通用 Desktop Entry 解析器，未覆盖的桌面执行条件仍须披露。

查询旧副本、无标记或被禁用的条目保持只读，不在启动时自动迁移。当前命令未启用不等于旧登录项不存在；用户明确重新开启时才更新本应用条目，明确关闭时仍须清理会继续执行的本应用旧项。迁移或真实开关的宿主测试前保存完整原字节/参数，测试后恢复，不只记录布尔值；用户明确请求的设置变更按请求保留结果。

隐藏登录启动仅在下游明确批准、且已有可靠恢复路径时接入。用本次进程的精确启动参数识别来源，不从“已开启自启”、父进程或近似参数推断；标记、注册命令和读取比较来自同一合同，不预置产品参数。托盘异步就绪时以有限总期限等待真实恢复入口，超时、失败或能力不支持就显示窗口；手动打开仍显示，重复登录启动是否唤醒现有实例按已批准行为明确处理。

`show=false` 只是创建意图，须核对当前 GPUI 后端是否仍在首次创建时 map。若有首次映射问题，按 [兼容补丁合同](../../desktop-manage-gpui-dependencies/references/compatibility.md) 定位精确版本，单独覆盖首次 map 次数及后续显窗，不把下游补丁复制成通用默认。完整登录过程、托盘丢失与恢复、纯 Wayland 和实际桌面呈现仍需目标宿主验证。

## Dock 与桌面身份

窗口 `app_id`、桌面文件标识、`StartupWMClass` 及图标名来自同一已确认身份。已批准 Logo 派生窗口 ARGB 图标和实际尺寸的 hicolor PNG；`_NET_WM_ICON` 读回只证明窗口属性，Dock 还须能解析有效 `.desktop` 和 `Exec`。隔离解包运行时宿主未必能访问包内路径，临时宿主映射须精确登记并恢复。最终包解包检查与真实 Dock 呈现分别取证，包布局与图标尺寸见 [Linux 打包合同](../../desktop-build-gpui-release/references/linux-packaging.md)。

Dock 窗口分组与软件中心应用发现是不同消费者。后者的 AppStream 包名关联、stock 图标可见性及安装/卸载边界按 [桌面安装集成](../../desktop-build-gpui-release/references/linux-desktop-integration.md) 核对，不能用窗口图标读回代替软件中心条目或事务证据。

## freedesktop 通知

[Desktop Notifications](https://specifications.freedesktop.org/notification/latest-single/) 的固定会话服务为 `org.freedesktop.Notifications`；`GetCapabilities` 只证明服务及其能力可查询，没有每应用授权查询。不可达和超时不伪装为用户拒绝。启动不投递测试消息，实际发送遵守应用偏好及 core 事件规则。

产品要求可控原生桥时，worker 拥有有界提交邮箱与通知 ID 映射，连接、认证和调用共享总预算。关闭、暂停投递和退出撤销尚未提交的命令；确定拒绝与未知回执分别处理，超时不盲目重投。服务唯一 owner 变化后丢弃旧 ID，只处理当前 owner 下本应用已发送通知的已批准动作，未知动作不恢复窗口。正文按纯文本转义，通知桌面入口和图标沿用产品身份。API Accepted、真实横幅和点击恢复分别验证；这些要求不表示 Kit 提交入口已实现上述原生桥。

## 热键与回归边界

Wayland 全局快捷键使用 [GlobalShortcuts Portal](https://flatpak.github.io/xdg-desktop-portal/docs/doc-org.freedesktop.portal.GlobalShortcuts.html)，管理真实会话、用户配置及实际返回的绑定集合；服务存在不等于授权或绑定成功。X11 注册需要 checked request 和确定的错误传播。`global-hotkey 0.8` 的 Linux 断连回执不能当可靠注册成功；具体库版本及补丁以目标清单和源码为准。依赖声明、空 action 合同和只读探测不构成后台服务或按键验证，也不授权注册键位。

协议回归使用 owned 私有 D-Bus daemon，不改变用户 session bus；产品桌面运行不要求用相同 daemon 实现。按实际修改覆盖托盘地址表示/归属/恢复入口丢失、显窗失败仍可重试、EWMH 撤回与最小化/重映射/其它 atom 保留、登录项只读与显式迁移、启动等待取消、通知迟到动作/未知结果和退出回收。真实 X11 测试处于 ignored 状态不等于已执行；完整候选另验真实桌面交互，并记录源码、包摘要、架构、桌面会话及未覆盖场景。历史候选早于新修复时，其通过不覆盖新机制；本次仅核对源码和单元结果也不代表当前候选已验收。
