# GUI 支持界面契约

本参考用于把 GUI 固定本地支持基线、产品差异、core 语义、宿主机制和出站能力分开。动态标题、默认收起的 Logo→版本侧栏、设置页、关于页与亮暗双主题赞助页随 GUI 初始化存在；只有修改基线、增加界面或启用出站能力时才填写相应产品实例栏目。

## 产品实例文档

初始化不创建 `docs/GUI_SUPPORT_SURFACES.md`。产品修改固定本地基线、增加其他界面或启用出站能力时，才按需从 `assets/brand-support/GUI_SUPPORT_SURFACES.template.md` 创建，并至少记录：

- 文档状态、确认来源和日期，以及关联的 Product Spec/应用资料；
- 对默认标题、侧栏、设置页、关于页或赞助页的修改，以及新增支持界面的 `enabled`、目的、路由或宿主落点、内容/i18n 键、本地资源及来源、可访问名称、主题与键盘行为；
- 标题差异及允许的动态占位符。默认公式固定为 `{applicationName} {version} {contactChannel}:{contactValue}`；展示名来自 `docs/GUI_APP_PROFILE.md`/Tauri 产品身份，版本来自当前打包元数据，联系人来自品牌 profile；
- 每个远程能力的独立出站记录；
- 未决字段、禁用原因、人工复核点和仍未验证的平台。

模板根不得包含这份产品实例文档。新增自然日项目记忆仍遵守各自的事件触发规则，不能用本文件替代 Product Spec、ADR、Product Status 或 Verification。

## 所有权矩阵

| 事实或行为 | 所有者 |
|---|---|
| 展示名、应用标识、品牌与窗口基础资料 | `docs/GUI_APP_PROFILE.md` |
| 固定标题、默认收起且顶部 Logo→版本的侧栏、设置/关于/赞助页及共享品牌资源 | GUI 初始化基线、`docs/GUI_APP_PROFILE.md` 与 Skill 的 `assets/brand-support/` |
| 默认基线差异、额外支持界面与出站清单 | `docs/GUI_SUPPORT_SURFACES.md` |
| 跨接口资格、值域、默认值、幂等与状态转换 | shared core |
| 窗口、系统浏览器、原生通知、平台元数据、Tauri capability | GUI Rust adapter |
| 路由、Mantine 展示、Query 生命周期、Jotai 纯交互状态 | React 前端 |
| 产品家族品牌联系人、赞助档位/价格/权益与媒体清单 | Skill 的 `assets/brand-support/`；修改需项目负责人重新确认 |
| 本地图片和静态说明 | GUI 打包资源；保留来源、内部复用批准、尺寸与 SHA-256 |
| 更新资格、最低支持版本与跨接口状态转换 | shared core；只消费 adapter 已认证的语言无关事实 |
| updater 检查/下载/安装、策略认证、平台元数据与任务回收 | GUI Rust adapter 与官方 Tauri updater |
| 统计同意、本地偏好、平台字段采集与 HTTPS 传输 | GUI Rust adapter；React 只展示和提交选择 |
| 权益、订单、支付、账户、发布渠道或强制更新策略配置 | 新产品/安全范围；不得由支持界面隐式创建 |

只属于宿主的标题设置或外部浏览器打开不需要虚构 core API。只要出现跨接口可复用的业务判断，就记录“GUI 事件 → core API → core 测试”，不能把它留在组件或 Tauri command。

## 出站记录

每个远程能力单独记录，不得用一个宽泛“允许联网”覆盖多个目的：

| 字段 | 要求 |
|---|---|
| 能力与目的 | 人类可理解且能对应产品范围；默认 `disabled` |
| 触发器 | 启动、用户动作、周期或其他精确事件；说明去重和并发 |
| 请求 | 方法、允许的 origin、路径模板、header/query/body 字段白名单 |
| 响应 | 类型化 schema、最大字节数、内容类型和未知字段策略 |
| 跳转/下载 | 允许的 scheme/host、重定向次数、是否交给系统浏览器 |
| 生命周期 | 连接/总超时、重试上限、退避、owner、取消与关闭回收 |
| 认证 | 只记录秘密引用名、运行时提供者和归属，不记录实值 |
| 隐私 | 同意方式、最小字段、标识符范围、保留期、删除/退出路径 |
| 失败语义 | 默认 fail-open；若渠道另有硬要求，记录独立批准与用户可见状态 |
| 可观测性 | 允许的脱敏事件和字段；禁止正文、秘密、绝对路径与个人数据 |

生产地址默认 HTTPS。禁止凭据嵌入 URL、任意重定向、无界响应、无限重试、后台 detached task、把失败当成功，以及在未批准时通过前端直接访问远程服务。

## 能力要点

### 侧栏、设置与关于/赞助入口

- 默认标题公式固定为 `{applicationName} {version} {contactChannel}:{contactValue}`。展示名与版本必须来自权威 Tauri/打包元数据，联系字段固定来自 profile 的 `contacts.windowTitle`；原生标题与 `document.title` 必须一致，不得写死一次构建值。
- 左侧菜单固定且默认收起；顶部始终先显示 `docs/GUI_APP_PROFILE.md` 选中的本地 Logo，再紧接当前版本，展开和折叠状态都不能隐藏二者。产品功能项从顶部向下增长；底部固定组按视觉顺序为赞助、设置、关于，即从底部向上为关于、设置、赞助。
- `/settings`、`/about` 与 `/sponsor` 是固定路由。设置页提供中英文切换、手动检查更新状态和统计上报同意；未配置远端能力时显示明确不可用状态并保持零出站。
- 关于页使用当前产品名称和版本，并固定展示作者 `about.studio`、profile 的 `contacts.support` 与三段免责声明。标语、许可、隐私或反馈动作仍由下游按真实事实注入；外部链接需独立批准、可识别、可键盘访问并通过系统浏览器打开。
- GUI 初始化完整复制品牌包的 `media/sponsor/*`，包括当前未引用小图，并核对 manifest。固定三档价格/权益、品牌联系人与双支付码是产品家族事实；支付码需要本地化替代文本。若产生订单、付款确认或权益状态，停止使用纯展示路径并进入独立产品/支付范围。
- GUI 初始化让 Mantine provider 默认跟随系统主题并同时保留亮色/暗色；Sponsor 依据运行时有效主题切换背景叠层、surface 与对比色，初始化机器的当前主题不能删掉另一套呈现。
- 选择更新视觉时可使用本地品牌 banner，但该图片不等于更新检查、下载或 endpoint 已获批准。
- 本地视频必须具有来源/内部复用批准、controls、字幕、文字稿和可选 poster，禁止 autoplay 与远程追踪资源；当前品牌包没有视频二进制。

### 更新检查

- 固定状态为 `NotConfigured`、`Idle`、`Checking`、`UpToDate`、`OptionalUpdate`、`RequiredUpdate`、`Failed`；失败不能伪装为最新版。配置完整时每个进程至多一次启动检查，手动入口始终复用单飞控制器。
- 当前版本来自打包元数据；启用自更新后使用官方 Tauri updater 和签名制品，默认拒绝降级、target/arch/channel 不匹配、任意跳转和嵌入凭据。桌面客户端不得内置服务端 secret 或发布私钥。
- 强更不信任远端布尔值。adapter 先验证最低支持版本策略的真实性、有效期与目标绑定，core 再执行严格 SemVer 比较；`RequiredUpdate` 由不可关闭的根级门阻断普通功能，只允许安装签名更新或安全退出。
- 检查、网络、策略认证或签名准备失败默认 fail-open；渠道确需 fail-closed 时必须独立批准离线、可用性与恢复风险。完整契约见 `update-and-telemetry.md`。

### 遥测

- 默认禁用且零出站，设置页使用明确同意开关。撤回同意必须取消在途请求、清空内存队列并阻止后续入队。
- 固定基线只允许每进程一次 `app_started`，通过 HTTPS JSON `POST` body 发送公开应用标识、应用版本、粗粒度 OS/架构、locale、distribution channel 和 UTC 时间；禁止 GET/query、稳定设备/安装 ID、用户名、主机名、精确路径、令牌、业务载荷或自由文本。
- 发送任务由应用生命周期拥有并可取消；最多一个在途请求、32 条内存事件和两次有界重试，不落盘，失败不阻断主流程。完整契约见 `update-and-telemetry.md`。

## 最小验证矩阵

- 固定本地界面：侧栏默认收起，Logo 在版本上方且两种状态都可见；功能项向下增长；底部顺序为赞助、设置、关于；`/settings`、`/about` 与 `/sponsor` 可达，Sponsor 分别通过亮色/暗色渲染，翻译回退、键盘与可访问名称有效。
- 标题：展示名与当前打包版本来自权威来源，联系字段来自 profile，原生标题与 `document.title` 一致，非法占位符被拒绝，设置失败不破坏主要业务。
- 关于页：作者、作者联系方式和三段免责声明完整；应用名与版本来自当前下游，不携带来源产品身份。
- 出站：禁用或未同意时请求计数为零；方法、origin、路径、字段、重定向、响应大小、超时和重试超界均失败关闭。
- 更新：未配置零出站；无更新、可选更新、认证策略的最低支持版本边界、畸形响应、target/channel 不匹配、制品签名、重复触发、取消和关闭回收均有确定结果；未认证布尔值不能触发强更。
- 遥测：默认/未同意/撤回均零出站；POST body 字段白名单、稳定标识符禁用、队列/重试上限、日志脱敏、生命周期回收和主要业务 fail-open 有非空测试。
- 供应链：Rust/TypeScript 源码、配置样例、测试夹具、日志和生产 `dist` 不含秘密实值、开发地址或未批准 endpoint。
- 品牌媒体：GUI Skill 内 13 个源文件均与 manifest 的 MIME、尺寸、字节数和 SHA-256 一致；GUI 应用默认包含完整 sponsor 媒体但不包含未选 updater banner，支付二维码字节未经优化或重绘。
