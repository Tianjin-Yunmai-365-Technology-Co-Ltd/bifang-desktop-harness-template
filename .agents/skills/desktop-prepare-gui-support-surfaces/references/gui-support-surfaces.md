# GUI 支持界面契约

本参考用于把支持界面的产品事实、core 语义、GUI 宿主机制和出站能力分开。只读取并填写本次已选择的部分，不把全部栏目当成必选清单。

## 产品实例文档

`docs/GUI_SUPPORT_SURFACES.md` 按需从 `assets/brand-support/GUI_SUPPORT_SURFACES.template.md` 创建，并至少记录：

- 文档状态、确认来源和日期，以及关联的 Product Spec/应用资料；
- 每个支持界面的 `enabled`、目的、路由或宿主落点、内容/i18n 键、本地资源及来源、可访问名称、主题与键盘行为；
- 标题模板及允许的动态占位符。展示名来自 `docs/GUI_APP_PROFILE.md`，版本来自当前打包元数据；联系人或营销文字只能来自已批准产品事实；
- 每个远程能力的独立出站记录；
- 未决字段、禁用原因、人工复核点和仍未验证的平台。

模板根不得包含这份产品实例文档。新增自然日项目记忆仍遵守各自的事件触发规则，不能用本文件替代 Product Spec、ADR、Product Status 或 Verification。

## 所有权矩阵

| 事实或行为 | 所有者 |
|---|---|
| 展示名、应用标识、品牌与窗口基础资料 | `docs/GUI_APP_PROFILE.md` |
| 已选择支持界面的内容、资源引用、开关与出站清单 | `docs/GUI_SUPPORT_SURFACES.md` |
| 跨接口资格、值域、默认值、幂等与状态转换 | shared core |
| 窗口、系统浏览器、原生通知、平台元数据、Tauri capability | GUI Rust adapter |
| 路由、Mantine 展示、Query 生命周期、Jotai 纯交互状态 | React 前端 |
| 产品家族品牌联系人、赞助档位/价格/权益与媒体清单 | Skill 的 `assets/brand-support/`；修改需项目负责人重新确认 |
| 本地图片和静态说明 | GUI 打包资源；保留来源、内部复用批准、尺寸与 SHA-256 |
| 权益、订单、支付、账户、发布渠道或强制更新政策 | 新产品/安全范围；不得由支持界面隐式创建 |

只属于宿主的标题设置或外部浏览器打开不需要虚构 core API。只要出现跨接口可复用的业务判断，就记录“GUI 事件 → core API → core 测试”，不能把它留在组件或 Tauri command。

## 出站记录

每个远程能力单独记录，不得用一个宽泛“允许联网”覆盖多个目的：

| 字段 | 要求 |
|---|---|
| 能力与目的 | 人类可理解且能对应产品范围；默认 `disabled` |
| 触发器 | 启动、用户动作、周期或其他精确事件；说明去重和并发 |
| 请求 | 方法、允许的 origin、路径模板、header/query/body 字段白名单 |
| 响应 | 类型化 schema、最大字节数、内容类型和未知字段策略 |
| 跳转/下载 | 允许的 scheme/host、重定向次数、是否交给系统浏览器 |
| 生命周期 | 连接/总超时、重试上限、退避、owner、取消与关闭回收 |
| 认证 | 只记录秘密引用名、运行时提供者和归属，不记录实值 |
| 隐私 | 同意方式、最小字段、标识符范围、保留期、删除/退出路径 |
| 失败语义 | 默认 fail-open；若渠道另有硬要求，记录独立批准与用户可见状态 |
| 可观测性 | 允许的脱敏事件和字段；禁止正文、秘密、绝对路径与个人数据 |

生产地址默认 HTTPS。禁止凭据嵌入 URL、任意重定向、无界响应、无限重试、后台 detached task、把失败当成功，以及在未批准时通过前端直接访问远程服务。

## 能力要点

### 标题与关于/支持入口

- 标题模板由产品选择，展示名与版本必须来自权威打包元数据；不得把一次构建值、某个联系渠道或另一个产品的文案固化为 Harness 公式。
- 关于/支持内容可以包含版本、许可、反馈或赞助入口，但只实现已批准项；外部链接需可识别、可键盘访问并通过系统浏览器打开。
- 当前产品名称、版本、功能和路由仍来自当前下游事实；关于页默认复用品牌 profile 的支持联系人，不得把来源产品名或功能文案固化为模板。
- 选择赞助页时完整复制品牌包的 `media/sponsor/*`，包括当前未引用小图，并核对 manifest。固定三档价格/权益、品牌联系人与双支付码是产品家族事实；支付码需要本地化替代文本。若产生订单、付款确认或权益状态，停止使用纯展示路径并进入独立产品/支付范围。
- 选择更新视觉时可使用本地品牌 banner，但该图片不等于更新检查、下载或 endpoint 已获批准。
- 本地视频必须具有来源/内部复用批准、controls、字幕、文字稿和可选 poster，禁止 autoplay 与远程追踪资源；当前品牌包没有视频二进制。

### 更新检查

- “检查是否存在版本”不等于“自动下载并安装”。只有前者获批时，不得增加自更新、强制退出或发布渠道逻辑。
- 当前版本来自打包元数据；服务响应必须有类型、大小和内容限制。下载地址需允许列表、无嵌入凭据，并由系统浏览器或已批准更新器处理。
- 强制更新、签名/hash 验证、回滚与渠道兼容性分别记录；不得从服务端一个未审字段直接获得不可关闭或远程指令能力。

### 遥测

- 默认禁用且零出站。启用前逐字段证明目的与最小化，记录同意、退出、标识符生命周期、保留和删除。
- 优先使用不跨安装持久的最小标识。稳定设备标识、账户关联或精确系统信息必须单独批准；不得上传自由文本、文件路径、令牌或业务正文。
- 发送任务由应用生命周期拥有并可取消；失败不阻断主流程，不用无限重试补偿。

## 最小验证矩阵

- 选中界面：路由/宿主入口可达、翻译回退、主题、键盘与可访问名称有效；未选界面不存在占位入口。
- 标题：展示名与当前打包版本来自权威来源，模板非法占位符被拒绝，设置失败不破坏主要业务。
- 出站：禁用或未同意时请求计数为零；方法、origin、路径、字段、重定向、响应大小、超时和重试超界均失败关闭。
- 更新：无更新、有更新、畸形响应、非允许下载地址、重复触发与取消路径均有确定结果；未批准的自更新或强制行为不存在。
- 遥测：字段白名单、同意撤回、标识符范围、日志脱敏、生命周期回收和主要业务 fail-open 有非空测试。
- 供应链：Rust/TypeScript 源码、配置样例、测试夹具、日志和生产 `dist` 不含秘密实值、开发地址或未批准 endpoint。
- 品牌媒体：GUI Skill 内 13 个源文件均与 manifest 的 MIME、尺寸、字节数和 SHA-256 一致；应用 bundle 只包含已选择表面的资源，支付二维码字节未经优化或重绘。
