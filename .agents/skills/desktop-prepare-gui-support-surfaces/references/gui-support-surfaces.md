# GUI 支持界面契约

本参考用于把 GUI 固定本地支持基线、初始化选择、产品差异、core 语义、宿主机制和出站能力分开。动态标题、语言与三态主题设置、应用级亮暗主题及设置页固定存在；侧栏采用精简或详细模式，关于页与赞助页按 GUI 初始化专门问询选择存在。只有修改所选基线、增加界面或启用出站能力时才填写相应产品实例栏目。

## 产品实例文档

初始化不创建 `docs/GUI_SUPPORT_SURFACES.md`。产品修改固定本地基线、增加其他界面或启用出站能力时，才按需从 `assets/brand-support/GUI_SUPPORT_SURFACES.template.md` 创建，并至少记录：

- 文档状态、确认来源和日期，以及关联的 Product Spec/应用资料；
- 对默认标题、侧栏、设置页、关于页或赞助页的修改，以及新增支持界面的 `enabled`、目的、路由或宿主落点、内容/i18n 键、本地资源及来源、可访问名称、主题与键盘行为；
- 标题差异及允许的动态占位符。默认公式固定为 `{applicationName} v{version} {contactChannel}:{contactValue}`；展示名来自 `docs/GUI_APP_PROFILE.md`/Tauri 产品身份，版本来自当前打包元数据并在展示边界规范化为一个小写 `v`，联系人来自品牌 profile；
- 每个远程能力的独立出站记录；
- 未决字段、禁用原因、人工复核点和仍未验证的平台。

模板根不得包含这份产品实例文档。新增自然日项目记忆仍遵守各自的事件触发规则，不能用本文件替代 Product Spec、ADR、Product Status 或 Verification。

## 所有权矩阵

| 事实或行为 | 所有者 |
|---|---|
| 展示名、应用标识、品牌与窗口基础资料 | `docs/GUI_APP_PROFILE.md` |
| 固定标题、初始化选定的精简/详细 Logo→版本侧栏、无隐私/统计区块的语言与三态主题设置、应用级亮暗主题、所选关于页/赞助页及共享品牌资源 | GUI 初始化基线、`docs/GUI_APP_PROFILE.md` 与 Skill 的 `assets/brand-support/` |
| 默认基线差异、额外支持界面与出站清单 | `docs/GUI_SUPPORT_SURFACES.md` |
| 跨接口资格、值域、默认值、幂等与状态转换 | shared core |
| 窗口、系统浏览器、原生通知、平台元数据、Tauri capability | GUI Rust adapter |
| 路由、Mantine 展示、Query 生命周期、Jotai 纯交互状态 | React 前端 |
| 语言与主题设备级偏好 | GUI adapter 本地偏好；主题由 Mantine color-scheme context 展示和切换，不进入 core |
| 产品家族品牌联系人、赞助档位/价格/权益与媒体清单 | Skill 的 `assets/brand-support/`；修改需项目负责人重新确认 |
| 本地图片和静态说明 | GUI 打包资源；保留来源、内部复用批准、尺寸与 SHA-256 |
| 更新资格、最低支持版本与跨接口状态转换 | shared core；只消费 adapter 已认证的语言无关事实 |
| updater 检查/下载/安装、策略认证、平台元数据与任务回收 | GUI Rust adapter 与官方 Tauri updater |
| 明确启用后的统计同意、本地偏好、平台字段采集与 HTTPS 传输 | GUI Rust adapter；产品级 React 界面只展示和提交选择，不复用默认设置页 |
| 权益、订单、支付、账户、发布渠道或强制更新策略配置 | 新产品/安全范围；不得由支持界面隐式创建 |

只属于宿主的标题设置或外部浏览器打开不需要虚构 core API。只要出现跨接口可复用的业务判断，就记录“GUI 事件 → core API → core 测试”，不能把它留在组件或 Tauri command。

## 出站记录

每个远程能力单独记录，不得用一个宽泛“允许联网”覆盖多个目的：

| 字段 | 要求 |
|---|---|
| 能力与目的 | 人类可理解且能对应产品范围；默认 `disabled` |
| 触发器 | 启动、用户动作、周期或其他精确事件；说明去重和并发 |
| 请求 | 方法、允许的 origin、路径模板、header/query/body 字段白名单 |
| 响应 | 类型化 schema、最大字节数、内容类型和未知字段策略 |
| 跳转/下载 | 允许的 scheme/host、重定向次数、是否交给系统浏览器 |
| 生命周期 | 连接/总超时、重试上限、退避、owner、取消与关闭回收 |
| 认证 | 只记录秘密引用名、运行时提供者和归属，不记录实值 |
| 隐私 | 同意方式、最小字段、标识符范围、保留期、删除/退出路径 |
| 失败语义 | 默认 fail-open；若渠道另有硬要求，记录独立批准与用户可见状态 |
| 可观测性 | 允许的脱敏事件和字段；禁止正文、秘密、绝对路径与个人数据 |

生产地址默认 HTTPS。禁止凭据嵌入 URL、任意重定向、无界响应、无限重试、后台 detached task、把失败当成功，以及在未批准时通过前端直接访问远程服务。

## 能力要点

### 侧栏、设置与关于/赞助入口

- 默认标题公式固定为 `{applicationName} v{version} {contactChannel}:{contactValue}`。展示名与版本必须来自权威 Tauri/打包元数据，展示边界先去除已有前缀再保证只有一个小写 `v`；联系字段固定来自 profile 的 `contacts.windowTitle`，原生标题与 `document.title` 必须一致，不得写死一次构建值。
- 左侧菜单由 `sidebar_mode` 决定。精简模式固定 `136px`，顶部 `56px` 本地 Logo 后紧接版本，每项使用 `30px` 图标在上、`11px`/`10em` 名称在下并持续显示完整名称，不提供折叠按钮。详细模式首次默认 `248px` 展开，顶部使用 `72px` Logo、菜单以图标+名称横排显示；拥有该动作的 ActionIcon 可收起为 `76px`，此时使用 `44px` Logo、只显示图标并以 Mantine Tooltip 补充名称。详细模式折叠状态通过独立 local-storage 键跨重挂载和下次启动恢复，不进入页面会话 Jotai store。两种模式都使用 `@tabler/icons-react` 命名组件、保留可访问名称和清晰选中态；产品功能项从顶部向下增长，底部按已选赞助、固定设置、已选关于的视觉顺序生成。
- `/settings` 是固定路由；`/about` 与 `/sponsor` 分别只在 `about_page = enabled`、`sponsor_page = enabled` 时存在并进入导航。设置页只提供当前应用/版本、中英文和浅色/深色/跟随系统；不得包含隐私标题、统计同意或未配置占位。所有 GUI 保存发布专用 `--config` Tauri 合并配置，正式构建才使用并将根日志逐字节嵌入。所选关于页在手动检查更新旁提供“更新日志”按钮；该按钮通过固定 Rust 异步命令从候选打包的 `release-notes.json` 查看最近 5 个版本，每版功能优化/问题修复各最多 10 条，全部版本只带一个小写 `v`，并有 loading/error/retry。未配置远端能力时检查更新显示明确不可用状态并保持零出站，本地更新日志仍可用。
- 所选关于页使用当前产品名称和版本，并展示手动检查更新、作者 `about.studio`、profile 的 `contacts.support` 与三段免责声明。标语、许可、隐私或反馈动作仍由下游按真实事实注入；外部链接需独立批准、可识别、可键盘访问并通过系统浏览器打开。未选择关于页时，不得保留隐藏路由、导航入口或不可达运行时组件。
- 页面交互事件绑定在实际拥有动作的按钮、链接、`Switch`、`Checkbox` 或菜单项，不由 Card、`Table.Tr`、`Table.Td` 等父级代理；父级有独立动作时只执行自己的语义并隔离冲突传播。表格中的 `Switch` 不得因点击行或单元格而切换。
- 页面工作状态使用共享 `pageSessionState.ts` 在应用根 Jotai store 中按页面持有活动选项卡、查询/筛选、排序和分页，只在当前程序进程内跨路由以及已启用的关闭隐藏/单实例唤醒过程保留；退出后回到默认值，不写入浏览器/Tauri/文件/数据库/URL，也不镜像 TanStack Query 或 core 数据。详细侧栏折叠偏好是独立设备级 UI 偏好，不属于页面工作状态。查询范围或每页数量变化时页码归 1；成功查询到大于第 1 页的空页时回退第 1 页，加载/错误和第 1 页空结果不循环。
- 仅在选择赞助页时完整复制品牌包的 `media/sponsor/*`，包括当前未引用小图，并核对 manifest。固定三档价格/权益、品牌联系人与双支付码是产品家族事实；支付码需要本地化替代文本。未选择赞助页时运行时 bundle 不得包含 sponsor 媒体。若产生订单、付款确认或权益状态，停止使用纯展示路径并进入独立产品/支付范围。
- GUI 初始化让 Mantine provider 默认跟随系统主题并同时保留亮色/暗色，分别定义页面背景、surface、主/次文字、边框与强调色；设置页允许浅色、深色、跟随系统并使用显式本地 manager 持久化。应用根和侧栏消费运行时有效主题；若选择 Sponsor，它还需切换背景叠层、surface 与对比色。初始化机器的当前主题不能删掉另一套呈现。
- 选择更新视觉时可使用本地品牌 banner，但该图片不等于更新检查、下载或 endpoint 已获批准。
- 本地视频必须具有来源/内部复用批准、controls、字幕、文字稿和可选 poster，禁止 autoplay 与远程追踪资源；当前品牌包没有视频二进制。

### 更新检查

- 选择关于页时，更新展示状态固定为 `NotConfigured`、`Idle`、`Checking`、`UpToDate`、`OptionalUpdate`、`RequiredUpdate`、`Failed`；失败不能伪装为最新版。配置完整时每个进程至多一次启动检查，手动入口始终复用单飞控制器。未选择关于页不代表远程更新获批，也不建立手动检查入口。
- 当前版本来自打包元数据；启用自更新后使用官方 Tauri updater 和签名制品，默认拒绝降级、target/arch/channel 不匹配、任意跳转和嵌入凭据。桌面客户端不得内置服务端 secret 或发布私钥。
- 强更不信任远端布尔值。adapter 先验证最低支持版本策略的真实性、有效期与目标绑定，core 再执行严格 SemVer 比较；`RequiredUpdate` 由不可关闭的根级门阻断普通功能，只允许安装签名更新或安全退出。
- 检查、网络、策略认证或签名准备失败默认 fail-open；渠道确需 fail-closed 时必须独立批准离线、可用性与恢复风险。完整契约见 `update-and-telemetry.md`。

### 可选遥测

- 默认禁用且零出站，初始化设置页不显示遥测或隐私控件。只有产品明确启用并记录相关产品/隐私事实时，才增加独立的产品级明确同意界面；撤回同意必须取消在途请求、清空内存队列并阻止后续入队。
- 固定基线只允许每进程一次 `app_started`，通过 HTTPS JSON `POST` body 发送公开应用标识、应用版本、粗粒度 OS/架构、locale、distribution channel 和 UTC 时间；禁止 GET/query、稳定设备/安装 ID、用户名、主机名、精确路径、令牌、业务载荷或自由文本。
- 发送任务由应用生命周期拥有并可取消；最多一个在途请求、32 条内存事件和两次有界重试，不落盘，失败不阻断主流程。完整契约见 `update-and-telemetry.md`。

## 最小验证矩阵

- 固定本地界面：按所选 `sidebar_mode` 验证精简 `136px` 持续名称且无折叠控件，或详细模式默认 `248px` 展开、图标+名称、自身按钮收起为 `76px`、图标-only + Tooltip 及偏好持久化；功能项向下增长，底部只按已选赞助、固定设置、已选关于生成。`/settings` 固定可达，`/about` 与 `/sponsor` 严格按选择存在或缺席；默认设置页没有隐私/统计控件或翻译键，浅色/深色/跟随系统回调和持久化有效，应用语义变量与所选 Sponsor 分别通过亮色/暗色渲染，翻译回退、键盘与可访问名称有效。
- 托盘 i18n：仅在选择系统托盘时，稳定 ID 不作为可见文字；中文精确显示“显示窗口/退出”，英文精确显示“Show Window/Quit”，不支持的 locale 回退英文，设置页运行时切换语言后无需重启即可刷新真实托盘菜单，任何 `tray.*` 原始键可见都失败。未选择时验证托盘资源和运行时接线缺席。
- 标题：展示名与当前打包版本来自权威来源，联系字段来自 profile，原生标题与 `document.title` 一致，非法占位符被拒绝，设置失败不破坏主要业务。
- 关于页：选择时验证检查更新及 `NotConfigured` 零出站、Rust 候选资源命令/handler/异步读取/失败关闭、前端 IPC 解码与加载失败重试、更新日志五版/十条裁剪、全部版本恰有一个 `v`、更新区父级不代理两个按钮、作者、作者联系方式和三段免责声明完整；应用名与版本来自当前下游，不携带来源产品身份。未选择时验证路由、导航、命令、加载器和运行时组件缺席。所有 GUI 仍验证发布专用映射精确存在。
- 页面会话：同一应用根 store 穿过 route unmount/remount 后仍保留 Tabs/查询/排序/分页，新 store 从默认值开始；成功空页回退第 1 页，loading/error 不回退且第 1 页不循环；源码不含页面会话持久化适配器或 Query/core 数据镜像。
- 出站：禁用或未同意时请求计数为零；方法、origin、路径、字段、重定向、响应大小、超时和重试超界均失败关闭。
- 更新：未配置零出站；无更新、可选更新、认证策略的最低支持版本边界、畸形响应、target/channel 不匹配、制品签名、重复触发、取消和关闭回收均有确定结果；未认证布尔值不能触发强更。
- 遥测：默认/未同意/撤回均零出站；POST body 字段白名单、稳定标识符禁用、队列/重试上限、日志脱敏、生命周期回收和主要业务 fail-open 有非空测试。
- 供应链：Rust/TypeScript 源码、配置样例、测试夹具、日志和生产 `dist` 不含秘密实值、开发地址或未批准 endpoint。
- 品牌媒体：GUI Skill 内 13 个源文件均与 manifest 的 MIME、尺寸、字节数和 SHA-256 一致；选择赞助页的 GUI 应用包含完整 sponsor 媒体且支付二维码字节未经优化或重绘，未选择时运行时 bundle 不含 sponsor 媒体；未选 updater banner 始终不进入 bundle。
