# GUI 更新、强更与统计上报契约

本参考只定义所有 GUI 下游共享的状态、所有权、安全和隐私边界。真实 endpoint、发布公钥、渠道、应用公开标识和隐私文本属于当前下游产品，必须写入受保护的 `docs/GUI_SUPPORT_SURFACES.md`，不得从参考项目复制。

## 固定界面与配置状态

- `/settings` 是 GUI 初始化固定路由，始终展示当前应用名和权威打包版本、中文/英文、浅色/深色/跟随系统和统计上报同意开关；手动“检查更新”和更新状态固定在 `/about`。
- 关于页存在更新入口不等于远程能力已启用。中性初始化把更新状态显示为 `NotConfigured`，禁用检查按钮；统计上报开关默认关闭且在未配置时禁用，所有请求计数必须为零。
- 用户语言与主题选择由 GUI adapter 本地持久化，分别覆盖系统语言/主题探测结果；主题选择 `auto` 时继续跟随系统。更新状态和统计同意不得写入 shared core 的权威业务存储。
- 产品启用更新或统计上报时才创建 `docs/GUI_SUPPORT_SURFACES.md`，并增加实际依赖、Tauri capability、配置和非空测试；不得为 Draft scaffold 填写虚假 endpoint 或发布事实。

## 更新状态机

关于页与根级强更门只消费下列稳定状态：

| 状态 | 语义 | 允许动作 |
|---|---|---|
| `NotConfigured` | 当前产品没有完整更新 profile | 不发送请求 |
| `Idle` | 已配置但本次进程尚未检查 | 手动检查 |
| `Checking` | 当前唯一检查正在进行 | 等待或由 owner 取消，不并发重复检查 |
| `UpToDate` | 已成功检查且当前版本不低于最新版本 | 继续使用 |
| `OptionalUpdate` | 存在签名可验证的新版本，但当前版本仍受支持 | 安装或稍后处理 |
| `RequiredUpdate` | 已验证策略表明当前版本低于最低支持版本 | 只允许安装更新或安全退出 |
| `Failed` | 配置、网络、解析、策略认证或签名准备失败 | 显示失败；默认继续使用当前版本 |

状态变化由 shared core 的纯语义用例决定，GUI adapter 只提供当前版本、经过认证的更新事实和宿主安装能力。React 不比较 SemVer、不读取远端布尔字段，也不把请求失败改判为“已是最新”。

## 检查与安装流程

1. 当前版本只来自 Tauri/打包元数据，并在进入 core 前解析为严格 SemVer。默认拒绝降级、预发布跨渠道和平台/架构不匹配。
2. GUI adapter 使用官方 Tauri 2 updater 插件检查和安装；生产构建必须启用更新制品生成。更新制品签名验证不可关闭，公钥可进入应用配置，私钥只能存在于批准的发布运行时。
3. 更新 profile 至少记录：启用状态、渠道、允许的 HTTPS origin/路径模板、目标平台/架构映射、更新制品公钥、强更策略公钥或等价认证机制、连接/总超时、最大响应字节、重定向规则、并发上限和失败语义。桌面 bundle 不能保密，禁止嵌入服务端 secret、共享口令或能代表发布者身份的长期凭据。
4. 可选的启动检查只在 profile 完整时每个进程执行一次；用户在关于页始终可以手动触发。启动检查与手动检查共享单飞控制器，重复触发复用当前结果，不创建并发请求。
5. 返回数据必须具有类型、内容类型和大小上限，未知关键字段、版本不合法、目标不匹配、任意 origin 跳转、URL 内嵌凭据或策略认证失败都进入 `Failed`。不能把失败解释成 `UpToDate`。
6. 下载和安装必须由官方 updater 处理，并仅消费与当前 target/arch/channel 精确匹配且签名验证通过的制品。外部浏览器下载不能实现“已验证自更新”或强更闭环。
7. Windows 安装期间 updater 可能退出当前进程；macOS/Linux 的重启语义按当前官方插件和渠道配置验证。应用退出前取消其他 owned tasks、停止接收新操作并等待有界回收。

## 强更判定与根级门

- 强更不是远端一个 `forcedUpdate` 布尔值。远端更新策略必须经过独立签名或等价的已批准认证，至少包含 `latestVersion`、`minimumSupportedVersion`、channel、target、arch、有效期和策略版本。
- GUI adapter 验证策略真实性、有效期和目标绑定后，才把规范化事实交给 core。core 使用严格 SemVer 判定 `currentVersion < minimumSupportedVersion`，并返回 `RequiredUpdate`；边界相等时不是强更。
- `RequiredUpdate` 由应用根级条件分支渲染，不使用可按 Escape、关闭按钮、遮罩点击或路由跳转绕过的普通弹窗。普通功能导航和业务页面不挂载，只保留“安装更新”和“退出应用”。
- 安装失败返回可重试状态和明确错误，不能静默解锁普通功能。用户仍可安全退出；更新服务不可达、策略无效或检查失败默认 fail-open，不得自动变成强更。若某渠道确需检查失败即阻断，必须单独批准并记录可用性、离线和恢复风险。
- 强更策略本身不能触发任意命令、删除数据、修改配置或跳转任意地址；它只影响更新状态和上述两项允许动作。

## 更新任务所有权

- 检查、下载和安装任务归应用生命周期控制器所有，使用 cancellation token、受管 join handle、单飞互斥和明确关闭顺序；禁止 fire-and-forget 或 detached spawn。
- 连接和总耗时均有上限；锁不得跨越不受控网络 `.await`。进度事件有界并可丢弃陈旧值，不能无界积压。
- 日志只记录脱敏的状态、渠道、目标、版本和稳定错误码；不得记录完整响应、签名私钥、凭据、带 query 的 URL 或用户数据。

## 统计上报同意与固定最小事件

- 统计上报是独立能力，默认关闭。首次启动和未同意时零出站；不得把安装、使用或检查更新视为同意，也不得用免责声明替代明确开关。
- 同意由 GUI adapter 保存在设备级本地偏好中。用户打开后只从下一次符合条件的事件开始发送，不回补同意前事件；关闭时立即取消在途上报、清空内存队列并阻止后续入队。
- 固定基线只允许一次每进程的 `app_started` 事件，使用 JSON `POST` body，字段精确为：`schemaVersion`、`eventName`、公开的 `applicationCode`、`applicationVersion`、粗粒度 `osFamily`、`architecture`、`locale`、`distributionChannel`、`occurredAtUtc`。
- 禁止使用 GET/query 传递事件；禁止稳定设备 ID、安装 ID、用户名、主机名、IP 派生字段、精确系统版本、绝对路径、文件名、窗口标题、命令参数、账号、令牌、业务载荷或自由文本。新增事件、字段或稳定标识符必须重新经过产品、隐私和适用法律批准。
- 桌面客户端不持有服务端 secret。若接收端要求认证，必须采用不会把长期发布者/服务端身份秘密放进 bundle 的批准方案；否则停止实现。

## 上报传输与回收

- endpoint 必须是产品 profile 中允许的 HTTPS origin/固定路径，不允许任意重定向、远程下发新 endpoint 或前端直接请求。
- GUI Rust adapter 拥有传输；React 只读配置状态并提交同意变化。shared core 只在统计资格需要跨接口复用时拥有语言无关的资格规则，不持有平台元数据或 HTTP client。
- 每个进程最多一个发送任务、一个在途请求和 32 条内存事件；不落盘。连接超时最多 5 秒、总超时最多 10 秒，失败最多重试 2 次，退避为 1 秒和 4 秒并带有界抖动；应用关闭、撤回同意或队列满时丢弃而不阻断主要业务。
- 统计失败始终 fail-open。日志只记录稳定事件名、结果码和队列计数，不记录 body、endpoint query 或设备信息。

## 产品实例必填事实

启用更新时至少填写：

- `enabled`、触发器、channel、允许 origin/路径、target/arch 表、当前版本来源；
- updater 制品公钥、强更策略认证公钥/机制及安全运行时私钥引用名；
- 响应 schema、最大字节、内容类型、超时、重定向、降级/预发布策略；
- `minimumSupportedVersion` 的发布权限、失效/回滚流程和用户可见恢复渠道；
- 各平台更新制品生成、签名、发布与真实安装验证状态。

启用统计上报时至少填写：

- 明确目的、同意文案、公开 `applicationCode`、distribution channel 和唯一允许事件/字段；
- HTTPS origin/路径、方法、内容类型、超时、重试、队列、保留与服务端删除期限；
- 接收方、隐私责任人、适用法律依据、退出/删除路径和用户可见隐私说明；
- 禁止字段清单、日志脱敏、零出站证明与真实撤回验证。

## 必需回归

- UI：版本在展开/折叠侧栏和设置/关于页可见；固定底部顺序为赞助、设置、关于；语言与三态主题切换持久化；关于页 `NotConfigured` 不触发请求。
- 更新 core：SemVer 的低于、等于、高于、预发布和非法值；只有认证策略的最低支持版本可产生 `RequiredUpdate`。
- 更新 adapter：目标/channel 绑定、响应大小、任意跳转、策略签名、制品签名、超时、取消、单飞和关闭回收；失败不伪装成功。
- 强更 UI：普通功能不可达，Escape/关闭/路由均不能绕过，仅安装与退出可用；可选更新不触发阻断门。
- 统计：未配置、默认关闭、未同意、撤回同意均为零出站；只使用 POST body 和固定字段；禁止稳定标识符；队列/重试有界且关闭后无遗留任务。
- 构建：已启用 updater 的每个平台候选同时存在官方更新制品及签名，发布私钥不进入源码、配置、日志、前端 bundle、manifest 或最终安装包。
